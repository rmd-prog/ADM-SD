Import Data Siswa

Gunakan CSV sederhana: nama,nis,kelas,absen. Import administrator akan menyimpan data langsung ke Cloudflare D1. Data lama akan diganti agar jumlah siswa sesuai CSV.

CP — Capaian Pembelajaran

CP terisi otomatis per rombel dan mata pelajaran. Kelas I–II = Fase A, III–IV = Fase B, V–VI = Fase C.

TP — Tujuan Pembelajaran

TP disusun per rombel dan mata pelajaran sebagai turunan operasional dari CP.

ATP — Alur Tujuan Pembelajaran

ATP sudah disediakan per rombel dan mata pelajaran; dapat disesuaikan dengan konteks sekolah.

Prota — Program Tahunan

Program tahunan terisi per rombel dan mata pelajaran. Alokasi waktu adalah rancangan awal dan perlu disesuaikan kalender pendidikan sekolah.

Prosem — Program Semester

Program semester terisi per rombel dan mata pelajaran, dibagi Semester 1 dan 2.

RPM — Rencana Pembelajaran Mendalam

Rencana Pembelajaran Mendalam (RPM) per rombel, mata pelajaran, dan BAB/Unit. Setiap RPM sudah memiliki identifikasi, dimensi profil lulusan, desain pembelajaran, pengalaman memahami–mengaplikasi–merefleksi, asesmen, diferensiasi, media, dan refleksi guru.

Penilaian Per BAB

Nilai dapat diinput per siswa dan per BAB/Unit. STS tidak digunakan. Guru hanya dapat menginput rombelnya.
