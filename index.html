Import Data Siswa

Gunakan CSV sederhana: nama,nis,kelas,absen. Baris pertama boleh berupa judul kolom.

CP — Capaian Pembelajaran

CP terisi otomatis per kelas dan mata pelajaran. Kelas I–II = Fase A, III–IV = Fase B, V–VI = Fase C.

TP — Tujuan Pembelajaran

TP disusun per kelas dan mata pelajaran sebagai turunan operasional dari CP.

ATP — Alur Tujuan Pembelajaran

ATP sudah disediakan per kelas dan mata pelajaran; dapat disesuaikan dengan konteks sekolah.

Prota — Program Tahunan

Program tahunan terisi per kelas dan mata pelajaran. Alokasi waktu adalah rancangan awal dan perlu disesuaikan kalender pendidikan sekolah.

Prosem — Program Semester

Program semester terisi per kelas dan mata pelajaran, dibagi Semester 1 dan 2.

RPM — Rencana Pembelajaran Mendalam

Rencana Pembelajaran Mendalam (RPM) per kelas, mata pelajaran, dan BAB/Unit. Setiap RPM sudah memiliki identifikasi, dimensi profil lulusan, desain pembelajaran, pengalaman memahami–mengaplikasi–merefleksi, asesmen, diferensiasi, media, dan refleksi guru.
